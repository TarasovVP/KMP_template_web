A native JavaScript and Vite application that consumes a Kotlin Multiplatform library compiled to an ES module.

This repository is the Web example from [**KMP: Integrating into Native Projects**](https://medium.com/@vptarasov/kmp-integrating-into-native-projects-f0f35091706d). It demonstrates how shared Kotlin logic can be used from a regular JavaScript project without making the web application itself a Kotlin or Gradle project.

## What the app demonstrates

- A small JavaScript application built with Vite.
- Consumption of Kotlin/JS output as a local npm dependency.
- Calls to functions exported from Kotlin with `@JsExport`.
- Native HTML and CSS presentation around shared KMP behavior.
- Preservation of symlinks so dependencies of the local Kotlin/JS package resolve correctly.

The page calls these exports from the shared module:

```javascript
import { getInfo, getDeviceModel, getOsVersion } from 'KMP_template_shared-shared';
```

It displays the shared greeting and date, the Browser or Node runtime, and the operating system inferred by the shared implementation.

## Shared dependency

The local dependency in `package.json` points to the production library generated by [KMP_template_shared](https://github.com/TarasovVP/KMP_template_shared):

```json
"KMP_template_shared-shared": "file:../KMP_template_shared/shared/build/dist/js/productionLibrary"
```

Keep the shared and web repositories as sibling directories:

```text
workspace/
├── KMP_template_shared/
└── KMP_template_web/
```

Generate the Kotlin/JS package before installing the web dependencies:

```shell
cd KMP_template_shared
./gradlew :shared:jsBrowserProductionLibraryDistribution
```

## Companion repositories

These independent repositories form the complete example from the article:

| Repository | Role |
|---|---|
| [KMP_template_shared](https://github.com/TarasovVP/KMP_template_shared) | Shared KMP library and Kotlin/JS package source |
| [KMP_template_android](https://github.com/TarasovVP/KMP_template_android) | Android consumer with Jetpack Compose |
| [KMP_template_ios](https://github.com/TarasovVP/KMP_template_ios) | iOS consumer with SwiftUI |
| [KMP_template_desktop](https://github.com/TarasovVP/KMP_template_desktop) | JVM desktop consumer with JavaFX |
| **KMP_template_web** | JavaScript consumer with Vite |

## Tech stack

- JavaScript ES modules
- Vite 6
- HTML and CSS
- Kotlin/JS IR production library
- `@js-joda/core` and `format-util`, required by the generated package

## Requirements

- Node.js 18+
- npm
- The adjacent shared repository with a generated production Kotlin/JS library

## Build and run

Clone both repositories into the same directory and generate the shared package first:

```shell
git clone https://github.com/TarasovVP/KMP_template_shared.git
git clone https://github.com/TarasovVP/KMP_template_web.git

cd KMP_template_shared
./gradlew :shared:jsBrowserProductionLibraryDistribution

cd ../KMP_template_web
npm install
npm run dev
```

Create a production web build:

```shell
npm run build
```

The generated site is written to `dist/`.

## Project structure

```text
KMP_template_web/
├── index.html       # Page structure
├── app.js           # Imports and calls the shared Kotlin/JS API
├── style.css        # Presentation
├── package.json     # Vite and local shared-package dependencies
└── vite.config.js   # Local-package symlink handling
```

## Later automation

[KMP_template_agents](https://github.com/TarasovVP/KMP_template_agents) was created later as a separate orchestration harness built around this already-existing example set. It automates shared package generation, dependency checks, web builds, and browser / Node smoke tests; it is not the source or parent project of this web application.

See [AI Agents for a KMP Developer](https://levelup.gitconnected.com/ai-agents-for-a-kmp-developer-82af4e8851a9) for that later automation layer.
